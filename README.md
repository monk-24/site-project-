# site-project-

Interactive sales dashboard for **The Real Pizza Company — Sutton Coldfield**.

Live site: https://monk-24.github.io/site-project-/

Built from the shop's order-level sales export (no raw order data is included in
this repo — only the aggregated dashboard). Features:

- Date range filter (all time, last 3/6 months, single month, custom range)
- Monthly net sales / orders / average order value / discounts trend
- Order mix — RPC's own channels vs. marketplace vendors (Uber Eats, Deliveroo, Just Eat)
- Weekly net sales trend
- Order patterns by day of week and hour of day
- Order type & take-home breakdown (dispatch type, payment method)
- Sales forecast to December 2026
- Marketing investment scenario planner (leaflets, digital, field marketing)
